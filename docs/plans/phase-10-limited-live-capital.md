# Phase 10 — Limited live capital

## Objective

Run only explicitly approved, smallest practical, liquid, low-leverage exposure
with immediate rollback and independent reconciliation.

## Work packages

1. Record explicit human approval, fixed loss/risk budget, allowed instruments,
   policy version, owner, and rollback conditions.
2. Begin with the least complex approved exposure at small size under heightened
   monitoring, deterministic risk, automatic kill, and independent reconciliation.
3. Prove correct cancel/exit/reconcile/risk behavior with API LLMs, Hermes,
   browser, gateway, and research workers stopped.
4. Freeze framework/model/source expansion during validation; a serious incident
   returns the system to paper.

## Exit gate

The system remains correct with all AI/research/browser services offline; any
serious incident returns it to paper.

## Explicitly out of scope

No automatic approval, no self-modifying strategy/limit/code, no concurrent
framework expansion, and no capital beyond the approved bounded budget.
